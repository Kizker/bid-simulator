2. Panduan Setup Awal (First-Time Deployment)

Lakukan langkah-langkah berikut di terminal SSH VPS Anda:

1 Akses Server VPS via SSH

ssh root@72.62.127.119

2 Masuk ke Direktori Domain FASTPANEL & Hapus File Bawaan

cd /var/www/fastuser/data/www/bidsim.labtry.my.id

# Hapus file placeholder index.html bawaan Fastpanel jika ada
rm -f index.html

3 Clone Repository dari GitHub

git clone https://github.com/Kizker/bid-simulator.git .

4 Sesuaikan Kepemilikan & Izin Eksekusi Berkas

chown -R fastuser:fastuser /var/www/fastuser/data/www/bidsim.labtry.my.id
chmod +x deploy.sh start.sh status.sh stop.sh

5 Instal Dependensi Proyek

npm install --omit=dev

6 Jalankan Server Aplikasi

# Menyalakan server dengan runner mandiri:
./start.sh

# ATAU menggunakan PM2:
npm install -g pm2
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup

3. Konfigurasi Reverse Proxy di FASTPANEL

Pastikan FASTPANEL meneruskan lalu lintas domain ke aplikasi port 3030:

A. Pengaturan Backend FASTPANEL

  1. Buka dashboard FASTPANEL di browser: https://72.62.127.119:8888.
  2. Klik kartu situs bidsim.labtry.my.id.
  3. Masuk ke menu Pengaturan / Settings ➔ Backend.
  4. Pilih Backend type: Proxy terbalik (Reverse proxy).
  5. Klik + Add dan masukkan Address: http://127.0.0.1:3030.
  6. Klik Simpan.

B. Dukungan WebSocket Socket.IO di Nginx

Nginx secara default meneruskan HTTP. Untuk memastikan WebSocket berjalan lancar tanpa terputus, pastikan blok Nginx situs Anda mengandung header Upgrade:

location / {
    proxy_pass http://127.0.0.1:3030;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}

4. Prosedur Deploy Lanjutan (Update Kode)

Setiap kali Anda selesai melakukan pembaruan kode di lokal dan melakukan git push ke GitHub, perbarui server dengan sangat cepat:

Opsi 1: Otomatis 1 Perintah dari Komputer Lokal

ssh root@72.62.127.119 "cd /var/www/fastuser/data/www/bidsim.labtry.my.id && ./deploy.sh"

Opsi 2: Dari Dalam Terminal SSH Server

cd /var/www/fastuser/data/www/bidsim.labtry.my.id
./deploy.sh

Script deploy.sh akan otomatis menarik kode terbaru, menyesuaikan permission, merestart server di port 3030, dan menguji respons tanpa menyentuh atau menghapus database.
