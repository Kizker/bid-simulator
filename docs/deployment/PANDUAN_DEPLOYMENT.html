Lakukan langkah-langkah berikut sekali saja saat pertama kali menyiapkan aplikasi di server hosting:

Buka terminal di komputer Anda, lalu masuk ke server hosting dengan perintah:

(Masukkan password akun hosting Anda saat diminta).

2 Masuk ke Direktori Domain & Bersihkan Folder Default

cd ~/domains/simbid.labtry.my.id/public_html

Salin file template .env.example menjadi .env:

3. Eksekusi Menjalankan Aplikasi (Pilih Metode)

Server Hostinger Anda mendukung dua pilihan metode deployment:

PILIHAN A: Menggunakan Docker & Docker Compose (Rekomendasi VPS)

Jika server hosting Anda memiliki akses Docker Engine, cukup jalankan perintah:

# Build image dan jalankan container di background
docker compose up -d --build

# Cek status container yang berjalan
docker compose ps

# Cek log aplikasi real-time
docker compose logs -f

Aplikasi akan langsung berjalan di container bid-simulator pada port 3000 dengan volume database otomatis tersimpan di folder host ./data.

PILIHAN B: Menggunakan Node.js Native & PM2 (Rekomendasi Cloud / Shared)

Jika server hosting tidak memiliki Docker, gunakan Node.js v20 dan PM2:

# 1. Pastikan pm2 terpasang (node & npm sudah bawaan server)
npm install -g pm2

# 2. Instal dependensi proyek
npm install

# 3. Kompilasi production build Next.js
npm run build

# 4. Jalankan aplikasi menggunakan PM2
pm2 start ecosystem.config.cjs

# 5. Simpan state PM2 agar otomatis hidup saat server reboot
pm2 save
pm2 startup

4. Konfigurasi Reverse Proxy (.htaccess)

Agar pengunjung domain https://simbid.labtry.my.id dapat mengakses aplikasi Next.js & Socket.io di port 3000, aktifkan file .htaccess di folder public_html:

cp .htaccess.example .htaccess

Isi konfigurasi .htaccess yang sudah disiapkan mencakup:

  • Proxy pass seluruh request HTTP ke http://127.0.0.1:3000.
  • Proxy pass protokol WebSocket (Upgrade: websocket) ke ws://127.0.0.1:3000.
  • Header X-Robots-Tag: noindex, nofollow untuk proteksi Anti-SEO agar tidak masuk ke Google.

5. Prosedur Deploy Lanjutan (Update / Perbaikan Kode)

Ketika Anda telah melakukan perbaikan kode di laptop dan melakukan git push ke GitHub, berikut cara memperbarui aplikasi di server:

Opsi 1: Otomatisasi 1-Klik via deploy.sh (Paling Cepat)

Masuk ke server via SSH dan jalankan script otomatis:

ssh -p 65002 u141095167@46.202.138.88

6. Manajemen Database SQLite & Keamanan Data

  • Lokasi Database: Seluruh data unit lelang, akun pengguna, karakter bot, dan histori penawaran tersimpan di data/simulator.db.
  • Sifat Persisten: File ini TIDAK AKAN HILANG saat update kode atau restart container karena sudah diproteksi oleh .dockerignore dan volume mount.
  • Cara Backup Rutin: Cukup salin file database sebelum melakukan update besar:
# Backup cepat database
cp data/simulator.db data/simulator_backup_$(date +%Y%m%d_%H%M%S).db
